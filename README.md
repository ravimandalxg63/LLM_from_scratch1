# Custom LLM Implementation from Scratch

A clean, modular, and scalable implementation of a Large Language Model (LLM) built from scratch. This project demonstrates core architectural concepts of modern autoregressive transformers, including multi-head attention, positional encodings, and optimization strategies for training and evaluation.

## 🚀 Features

- **Transformer Architecture**: Full implementation of decoder-only transformer blocks.
- **Custom Attention Mechanism**: Multi-Head Self-Attention with causal masking.
- **Configurable Hyperparameters**: Easily tweak embedding dimensions, number of heads, layers, and context length.
- **Training Pipeline**: Integrated scripts for data preprocessing, tokenization, and model training with loss tracking.
- **Text Generation**: Efficient inference engine with top-k/top-p sampling and temperature scaling.
